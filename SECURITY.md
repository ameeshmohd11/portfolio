
# Security Policy

The security of my personal website and projects is important to me. I appreciate everyone who helps identify and report potential security issues.

## Supported Versions

I focus on maintaining the security of the latest version of my personal website.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ |
| Older versions | ❌ |

Only the latest maintained version is guaranteed to receive security updates.

## Reporting a Vulnerability

If you discover a security vulnerability on my website or in one of my projects, please report it responsibly.

- **Email:** ameeshmohd11@gmail.com
- **GitHub:** [@ameeshmohd11](https://github.com/ameeshmohd11)

When reporting a vulnerability, please include:

- A brief description of the issue.
- The affected page, feature, or project.
- Steps to reproduce the issue.
- Screenshots or other supporting evidence, if available.

## Response Process

- I aim to acknowledge security reports within 7 days.
- Confirmed vulnerabilities will be investigated and addressed as appropriate.
- If a report is not considered a security vulnerability, I will explain why where possible.
- I will provide updates on the investigation and resolution when practical.

## Responsible Disclosure

Please report vulnerabilities privately before sharing them publicly.

Do not access or modify other people's data, disrupt services, or exploit vulnerabilities beyond what is necessary to demonstrate the issue.

Thank you for helping me keep my website and projects secure.
