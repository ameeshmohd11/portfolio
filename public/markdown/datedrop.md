# DateDrop

**DateDrop** is an automated document organization utility designed to effortlessly sort, organize, and categorize files and documents into dedicated date-stamped and category-specific folder hierarchies.
 
---

## Key Features

- **Automated Sorting**: Automatically detects creation or modification dates and moves documents into structured date folders (e.g. `YYYY/MM/DD`).
- **Custom Rules**: Define filters by file extension, tags, document types, or naming conventions.
- **Bulk Processing**: Batch organize large volumes of loose files, receipts, invoices, and study materials in seconds.
- **Clean Workspace**: Keeps your Downloads, Desktop, and project directories organized effortlessly.
