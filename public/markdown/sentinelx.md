# SentinelX

**SentinelX** is an intelligent, real-time crisis alert and emergency safety response system engineered for Android devices.

---

## System Features

- **Real-Time Emergency Alerts**: Broadcasts instant push alerts and geo-located warnings during critical situations.
- **One-Touch SOS & Geolocation**: Transmits precise GPS coordinates and emergency distress pings to designated emergency contacts.
- **Incident Mapping**: Live map overview displaying reported local crisis incidents, danger zones, and safe evacuation corridors.
- **Offline Fallback**: SMS-based emergency fallback mechanism when mobile data or internet connectivity is unavailable.

---
